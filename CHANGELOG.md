## 1.3.0

- Add macOS playback support with texture rendering.
- Upgrade iOS/macOS to the FFmpeg 8 ijkplayer kernel.
- Use an arm64 simulator slice for the iOS kernel (no x86_64 simulator).
- Move optional panels and overlays into the new `fplayer_ui` package.
- Harden player lifecycle, equality, platform guards and view listeners.
- Generate channel/method/event/state constants from one protocol spec.
- Modernize Android toolchain and example project.
